## 1. 缺陷现象与根因

用户在浏览器打开 `experiment/dashboard_20261110/dashboard.html` 时，`view-02`（同步时间轴与阶段步进）出现两处可见错误：

1. 每个阶段胶囊 `.chip` 从中间断裂成左右两个半圆弧（`border-radius:999px` 的圆角边框被拆开）；
2. 胶囊没有横向排列，而是每个 `<small>` 强制换行后整列竖向堆叠。

根因（经源码定位确认）：

| 编号 | 位置 | 机理 |
|---|---|---|
| R1 | 旧 `_CSS` 的 `.chip` | 只写了 `border/padding/font-size`，**未声明任何盒模型**，`:root` 默认落在 `display:inline`；而 `.chip small{display:block}` 是块级子元素。按 CSS 规范，行内盒不得包含块级盒，浏览器做 **inline-box splitting**（把行内盒拆成多个片段），胶囊边框因此从中间断开，`<small>` 也各占一行。 |
| R2 | 旧 `_JS` 的 `renderTimeline()` | 直接把 `<span class="chip">` 拼进 `<p>` 文本流，没有使用静态区已有的 `.chips` 弹性容器，导致静态区与动态筛选区排版不一致、且更易触发断裂。 |

原静态 `view-02` 虽然包了 `.chips`，但 `.chip` 自身仍是行内盒，因此同样撕裂——这是两处缺陷共同作用的结果。

## 2. 修复内容

### 2.1 `.chip` 块级化（R1）

`_CSS` 中 `.chip` 现为显式弹性盒，块级子元素 `small` 合法且不再拆分：

```css
.chip{display:inline-flex;flex-direction:column;align-items:flex-start;justify-content:center;
vertical-align:middle;gap:1px;border:1px solid var(--line);border-left:3px solid var(--accent,#cbd5e1);
border-radius:10px;padding:5px 10px;font-size:11px;line-height:1.3;background:#f8fafc;
white-space:nowrap;max-width:100%}
.chip small{display:block;color:var(--muted);font-size:9px;line-height:1.25;font-variant-numeric:tabular-nums}
```

`border-radius` 由 `999px` 改为 `10px`（多行内容不再需要半圆端点），并加 3px 左侧相位色条（`--accent`），六类阶段各有独立配色，保持可辨识度。

### 2.2 静态与动态时间轴统一结构（R2）

静态 `_sections["view-02"]` 与动态 `renderTimeline()` 现在生成**完全相同**的结构：

```html
<div class="timeline">
  <div class="timeline-row">
    <div class="timeline-head"><strong>TOPIC_01 / B01</strong><small>23 个阶段节点</small></div>
    <div class="chips">…23 个 .chip…</div>
  </div>
  …
</div>
```

`.timeline-row` 用两列网格（`158px minmax(0,1fr)`）把「区组标题」与「阶段胶囊流」分开；`.chips{display:flex;flex-wrap:wrap;gap:8px;min-width:0}` 保证同一行横向流式排列、窄屏自动折行；`≤760px` 时降为单列。所有 23 个阶段按逻辑序号 `T0 → 曝光R1–R8 → T1 快照 → T1-A/B/C/D → 六臂分支 → 干预R1–R2 → T2 → 保持R1–R4 → T3 主终点` 排列。

### 2.3 其余 10 个视图的巡检与升级

| 项 | 处理 |
|---|---|
| 行内块嵌套全页巡检 | 全页仅 3 处 `<span>` 含 `<small>`：两处 `.chip`（已块级化）、一处 `.banner` 内的 `small`（父元素是 `div`，合法）。另将 `#live-status` 的 `span.meta` 改为独立整行显示。审计器逐元素复核，当前冲突数 0。 |
| 宽表横向滚动 | `_table()` 输出统一包 `<div class="table-wrap">`；`.table-wrap{overflow-x:auto}`、内表 `min-width:520px`；`.live{overflow-x:auto}` 覆盖全部 JS 动态表格；新增 `tblWrap()` 包装 `renderSeries / renderInterventions / renderTrace / renderFlow / renderCalibration / renderCoverage / renderNetwork`；`th,td{overflow-wrap:anywhere}` 防止长哈希撑破。 |
| 网络回放网格 | `view-03` 由单列大表改为 `.net-grid{display:grid;grid-template-columns:repeat(auto-fit,minmax(240px,1fr));gap:12px}`，`≥1100px` 固定 3 列、`≤900px` 降列；6 张 `.net-card`（拓扑 SVG + 边统计 + 说明）。同时把动态 `renderNetwork()` 改为紧凑筛选表——原先它会再画 6 张 SVG，与静态网格**重复渲染**，现只在静态网格上方给筛选结果表。 |
| 粘性顶栏衔接 | `.banner` 与 `.filters` 合并进唯一 sticky 容器 `.topbar{position:sticky;top:0}`；`.filters` 不再自带 `position:sticky`，删除硬编码 `top:56px` 偏移。横幅折行变高时整组一起下移，**不再遮挡筛选器**。`≤760px` 与打印时整组改为静态流。 |
| 其余细节 | `code{overflow-wrap:anywhere}`、`.kpi-value` 断行、`select/button` 对齐、`section.view{min-width:0}`、打印时 `.net-grid` 固定 3 列、`h1` 行高与 `header` 间距微调。 |

### 2.4 自动防回归

`verify_dashboard_bundle` 新增第 9 项 `_ui_layout_audit(html)`，把本次缺陷固化为硬断言（任一不满足即 `passed=False`）：

- `ui_chip_display`：`.chip` 的 `display` 必须是 `inline-flex/flex/inline-block/block` 之一，且含 `flex-direction:column`，`.chip small` 仍为 `display:block`；
- `ui_chip_display_not_block_level`：若被改回 `inline` 立即报错；
- `ui_timeline_rows` / `ui_timeline_chips_missing`：静态至少有 6 个 `.timeline-row`，且每行紧跟 `.chips` 容器；
- `ui_timeline_renderer_layout_regression`：从 HTML 抽出 `renderTimeline()` 函数体，必须同时含 `timeline-row` 与 `chips`，且不得退回 `<p><strong>` 拼接；
- `ui_table_wrap_scroll_missing`：`.table-wrap` 必须声明 `overflow-x:auto`；`ui_js_table_wrap_missing`：JS 必须使用 `tblWrap()`；
- `ui_network_grid_missing`：HTML 必须有 `.net-grid` 且 ≥6 个 `.net-card`；`ui_network_renderer_duplicate_graphics`：`renderNetwork()` 内不得再出现 `<svg>`；
- `ui_topbar_missing` / `ui_filter_double_sticky` / `ui_filter_fixed_offset_regression`：顶栏只允许一个 sticky 容器，且不得残留 `top:56px`；
- `ui_inline_block_conflict`：全页扫描，任何 `<span>` 内含 `<small>` 或块级子元素（`div/p/ul/ol/table/section/figure/h1–h6/blockquote`）即失败。

`verification.json` 顶部新增 `ui_layout` 段（`chip_display`、`timeline_rows`、`network_cards`、`topbar_single_sticky`、`inline_block_conflicts`）。
