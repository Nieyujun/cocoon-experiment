## 3. 数据契约与隔离

### 公共问卷

- 顶层仅`schema_version="1.0"`、`questionnaire_id`、`topic_id`、`anchor_items`、`is_demo: bool`，以及可选`transfer_items`。
- 锚题恰8项；迁移题缺省归一为空列表，或空列表/恰4项。所有item_id在两组中合并唯一。
- 每题仅`item_id`、`statement`；ID严格ASCII格式并检查答案标签词，拒绝gold/truth/is_accurate/stance/answer/analysis等及真假/答案标记，正文是非空有效Unicode纯文本。
- 拒绝HTML、编码HTML、控制/不可见字符、未允许字段及敏感键；不会把题干中的普通“真假”讨论误作标准答案，但公共问卷不能附加六维清单或私有字段。

### 私有评分依据

原始私有包为：

```text
schema_version, questionnaire_id, topic_id, is_demo,
gold_answers: [{item_id, partition: "anchor"|"transfer", truth: int 0|1}],
dimensions: [{dimension_id, name, criteria}] 共6项,
opposing_rubric: {
  summary: {"0": text, "1": text, "2": text},
  main_evidence: {"0": text, "1": text, "2": text},
  boundary: {"0": text, "1": text, "2": text}
}
```

题目与分区精确对应公共包，不多不少，真值拒绝bool；6维ID唯一，量规每项完整。返回`validated_private_gold_v1`评分侧封装，保存原bundle、公共问卷副本及各自哈希。后续盲评构造/计分使用该校验封装，不接受不带验证绑定的裸gold字典。

这个封装包含私有gold，**只能留在控制器/评分侧，不能整体发送给受试或助手**。本轮没有生成正式gold文件；仅测试封闭合成夹具。

### 测量状态适配

当前工程状态尚无真实送达列表，本轮定义显式适配字段，不把`prepared_inputs`误当已曝光：

```text
world_state:
  agents: [{agent_id, ...}, ...]
  messages: {agent_id: [{role, content}, ...]}
  timepoint: T0|T1|T2|T3
  is_demo: bool
  system_prompt: 可选纯文本公共提示
  exposure_history: [
    {event_id, event_type, agent_id, status, sent_to_model: bool, cards: [公共卡片...]}
  ]
```

- 调用`runtime.measurement_view`取得深拷贝，只使用指定Agent的可见消息和可选公共system_prompt，不传整个世界、其他人发言、画像立场、控制器记忆或私有gold。
- 白名单仅来自该Agent的`exposure_delivered`、`status="delivered"`、`sent_to_model=True`记录。库存、其他人记录和prepared记录不计入；同ID卡片内容漂移、事件重复及矛盾状态拒绝。
- 卡片字段依scheduling公共白名单，元数据反泄露；历史中显式序列化的gold/六维等私有字段拒绝。任意自然语言中的隐含答案无法靠字段校验保证识别，上层仍须隔离来源。
- 不重新曝光卡片全文、不改写原历史，只追加公共测量指令和问卷；白名单证明是“曾按输入记录送达”，并不保证该卡仍在截断后的当前记忆中。
- 只允许显式allow_demo=True使用演示状态；问卷、状态与选中卡片演示标记一致。
- **仅返回`messages`是受试发送候选。** 外层timepoint、来源事件ID及状态哈希只供控制器，不得整包发送。
- 原world_state前后哈希一致，返回子对象无共享写引用，`measurement_writes_to_memory=False`。这是无写回的构建API，不是操作系统级只读保护；上层不得将回答追加回社交记忆。

## 4. 附录B解析与T1桥接

原始JSON只能有`answers`、`evidence_notes`、`opposing_view`，拒绝围栏、重复键、NaN/Infinity及溢出指数。

- answers允许0至全部题目；拒绝未知或重复ID，不补缺题概率。p_true为有限非bool数值0..1；choice可省略，否则严格bool或整数0/1。reason非空、引用不重复且限已见card ID。
- evidence_notes为1..30项，每项只有known_evidence和remaining_question，均非空纯文本；opposing_view固定三个分项。单项文字最多4000字符、原始响应最多200000字符。
- 解析返回`validated_measurement_v1`控制器封装，保留raw_text/output/问卷/可见ID与hash。`timepoint`为上层显式参数，默认None；不能从题目ID猜测T1。
- 桥接只接受timepoint=T1且问卷一致的校验封装，按固定问卷题序及原notes顺序拼接文本。所有brief_reason、known_evidence、remaining_question和三项opposing原文均为user_view连续子串，不截断、不改写。
- 输出user_view为>=10字符有效纯文本、无控制符，SHA-256按UTF-8原字节计算。端到端测试证明`contracts.parse_stage_output(..., "mirror", ..., user_view=...)`能逐字核查user_quote。
- 本模块不承认来源事件真实性：封装与桥接的`source_event_ids=[]`、`actual_observation_verified=False`。上层需另外记录真实调用事件与is_demo，不能修改已校验封装谎称获验证。

## 5. 盲评与完整计分

### 评估器实际输入

仅含五字段：`blind_sample_id`、`evidence_notes`、`opposing_view`、`dimensions`、`opposing_rubric`。

**不含answers、p_true、gold_answers、问卷ID、时点、组别、世界或Agent标识。** 示例任务标识和文本显式出现I0–I5/T0–T3/S01/world/env/block/seed/balanced/homogeneous等即拒绝；检查覆盖ID、notes、opposing及量规全文。大小写、常见驼峰、全角与编码变体纳入检查，不将污染文字静默删改为合格。

### 评估器输出

- 必须匹配blind_sample_id；六维依私有定义原序返回dimension_id/mastered/recognized_gap/evidence_quote。
- 布尔值严格，不接受1/0；任一旗标为True时引文必需。任何非null引文都须是某条受试evidence_notes字段的精确连续子串，不能引量规、opposing或跨字段拼接文本。
- mastered与recognized_gap同时True允许，但计分掌握优先；识别缺口只计`not mastered and recognized_gap`。
- opposing_scores含三项严格整数0..2及非空rationale。解析返回与blind_packet哈希绑定的`validated_blind_evaluation_v1`封装。
- 这些检查不判断引文是否真正证明掌握，也不替代独立评估器与人工评分质量审核。

### metrics直接对接

- `metrics.score_answers`按anchor/transfer分别调用，主锚题分母恒8，可选迁移分母4；绝不混成12题主终点。
- 缺题的BS/Acc/S为None，BS_lower/BS_upper遵循现有完整分母口径；不填概率。
- 有经过重新校验的blind_evaluation时才调用`coverage_score`与`understanding_score([summary, main_evidence, boundary])`。评分前重建应对应的盲评包，拒绝不同文本/量规混用。
- 未提供盲评时客观分正常输出，O/U/coverage为None、`blind_evaluation_status="pending"`。
- 分数不包含真值表，不写回受试；仍`formal_eligible=False`。盲样本映射须由上层私有记录管理；相同主观文本/量规的不同真实个体无法仅由本地哈希认证区分。
