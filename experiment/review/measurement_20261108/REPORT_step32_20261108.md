### 2.1 个体面板 → 网络聚合
- 输入严格为步骤31 `reconciled_blind_panel_v1`：核对 contract、`panel_sha256`（`runtime.canonical_hash(panel_records)`）、样本唯一性、`controller_private_only / send_to_evaluator / writes_to_memory / new_model_calls / formal_eligible` 身份位，逐行核对8锚题 `anchor`、探索性 `transfer`、客观/盲评完成旗标与BS上下界。
- `expected_agents_per_world` 直接调用 `scheduling._check_population_size`：整数且 `>=8`、`%4==0`。
- 按 `(topic_id, block_id, world_id, environment, arm, timepoint)` 聚合。**只有该网络恰好 `expected_agents_per_world` 名Agent全部存在且指标完整，`BS/Acc/S/O/U` 精确网络均值才有效**；否则为 `None`、`valid=False`，绝不用剩余个体均值冒充完整网络均值。
- `BS_lower_mean` / `BS_upper_mean` 始终以**固定期望人数为分母**：已有个体取自身 `BS_lower/BS_upper`，完全缺失个体按 `[0.0, 1.0]` 极值计入。`transfer` 摘要独立保存并标 `primary_endpoint_separate=True`，不混入8锚题主终点。
- `is_demo=True` 的输入默认拒绝；仅 `allow_demo=True` 放行，且顶层强制 `is_demo=True`、`formal_eligible=False`。

### 2.2 2×2 曝光效应
- 按 `(topic_id, block_id, environment∈A/B/C/D)` 取 `T0/T1` 配对；校验同世界 T0/T1 条件一致；`d = T1 - T0`，任一不完整则该区组 `valid=False, change=None, contrasts=None`。
- 直接调用 `metrics.exposure_contrasts` 输出同质效应 `((d_C+d_D)-(d_A+d_B))/2`、错误信息效应 `((d_B+d_D)-(d_A+d_C))/2`、交互效应 `(d_D-d_C)-(d_B-d_A)`。
- `metric=="BS"` 时追加 `bounds_from_missingness`：由网络级 `BS_lower_mean/BS_upper_mean` 极值配对推导三类效应的上下界；非BS指标明确 `bounds_scope="not_applicable_non_BS_metric"`。
- 按议题等权汇总，任一议题无完整区组则 `overall.estimable=False`；给出 `expected_blocks / complete_blocks / missing_blocks / coverage`。
- **阶段隔离**：若面板同时存在未分配臂的曝光网络与干预臂 T1 网络，2×2只取未分配臂的前测网络，返回 `exposure_arm_scope="unassigned_pre_intervention_networks_only"`。这是阶段选择，不是丢弃缺测个体；阶段内缺测仍由 `valid` 与边界保留。

### 2.3 干预效应与随机化检验
- 提取环境D（可由 `environment` 指定）六臂 `I0–I5` 的共享 `T1` 起点与 `T2`/`T3` 终点；同区组各臂 T1 绝对差 `<=1e-12`，否则拒绝，禁止跨区组混配。
- 统一转换为**归一化损失**（BS/S/O 越低越好取 `x/scale`；Acc/U 越高越好取 `(max-x)/scale`），再调用 `metrics.paired_summary`，因此 `T1/T3` 始终落在 `[0,1]` 且效应方向一致：`benefit = 对照变化 − 处理变化`，正数表示处理组改善更多。返回的 `effect`、`ci_95`、各层 `control/treatment` 再乘回原量纲，并保留 `paired_summary_effect_normalized_loss` 供追溯。
- 主确认性比较：`I4_vs_I0`、`I4_vs_I5`（`comparison_family="primary_confirmatory"`）；次要策略比较 `I1/I2/I3/I5_vs_I0` 明确标为 `secondary_exploratory`，不给确认性 p 值。
- **`allocations is None`**：`p_raw`、`p_adjusted` 全部为 `None`，并原样保留 `metrics.paired_summary` 的 `p_value_note`，不做 sign-flip 伪造。
- **提供 `allocations`**：逐区组用 `scheduling.allocate(arms, seed)` 重建槽位表，核对 `slot/arm/response_seed` 与实际网络记录的 `(topic, block, arm)`、世界、环境完全一致；未登记区组、篡改响应种子、重复臂、缺观测均拒绝。
  - 用局部 `random.Random(seed)` 在**每个完整有效区组内**重排六臂标签，两项确认性比较各自维护独立置换统计量；采用 Phipson-Smyth 保守双侧口径 `(1 + count(|stat_perm| >= |stat_obs|)) / (1 + permutation_reps)`，不会出现 0 p 值。
  - 直接调用 `metrics.holm(dict(p_raw))` 得到两项 `p_adjusted`（`metrics.holm` 的实际签名是 `dict[str,float] -> dict[str,float]`，不是列表；此处按真实接口调用，语义与指令一致）。
  - 有实际分配时，`metrics.paired_summary` 的确认性记录限定为**同一批完整有效区组**（其余区组仅标 `valid=False`，仍留在 `expected_n` 分母），使报告的效应与置换检验的观测统计量严格同分母、同区块；返回 `confirmatory_records_restricted_to_complete_allocation_blocks=True`。
  - 存在缺测区组时仍可给出基于完整子集的条件推断 p 值，但显式标 `randomization_scope="conditional_on_complete_blocks_only"` 并在 `p_value_note` 说明覆盖率不是全实验覆盖率；不把条件 p 值冒充预注册全样本检验。
- 另输出 `BS_lower/BS_upper` 缺失敏感性边界、各议题 `n / expected_n / count_missing / coverage`、`independent_unit="paired_network_block_not_individual_agent"`；顶层 `formal_eligible=False`、`new_model_calls=0`。

## 3. 与指令字面表述的差异（已在实现/测试中明示）

1. **`metrics.holm` 接受 dict 而非 list**：按现有算子真实签名调用 `metrics.holm({"I4_vs_I0": p, "I4_vs_I5": p})`，返回同键校正值。未修改 `metrics.py`。
2. **演示/合成演练调用 `metrics.exposure_contrasts`**：该算子本身无 `is_demo` 门禁，实现用 `_ControlledDict` 受控克隆并附 `_analysis_controlled_demo_clone` 标记后调用，外层恢复 `is_demo=True`、`formal_eligible=False`；`metrics.paired_summary` 有 `is_demo` 拒绝，合成夹具记录用同样受控克隆强制 `is_demo=False`，外层仍如实标 `is_demo=True`。**这不改变输入数值语义，也不修改旧模块**。
3. **非BS指标的缺失边界**：`bounds_from_missingness` 只对BS有意义；其他指标返回 `not_applicable_non_BS_metric`，而不是误用BS边界。
4. **`reconcile_blind_evaluations` → `analysis` 闭环**：项目当前没有 `analysis.py` 之外的下游统计消费者（无 `analysis.py` 的旧版本、无 `build_extractive_control`）；闭环测试覆盖到 `analyze_exposure_2x2`，干预侧闭环用合成网络聚合验证，均不虚构不存在的入口。
5. 原方案第11节为固定议题条件推断；本模块不重采样议题、不向议题总体泛化，返回 `analysis_scope` 明确标注。

- 本层是**统计口径与格式校验**，输入面板的真实性、匿名映射是否来自真实控制器、盲评是否由独立评估器完成，均需外部可信事件与签名锚；自含哈希不是数字签名。

- 真实人审仍为 **0**，55项110审核位全部 pending；原长报告11项AI语义问题、来源权利、议题轴适用性、108卡材料集、独立金标准、真实T1与完整个性化镜像、OASIS/受试与评估模型、正式实验预算与版本冻结均未完成。
- 仅有完整有效区组时 p 值为条件推断；`coverage` 以已出现区组为分母，不能当作全实验覆盖率。
- `metrics.paired_summary` 的 `ci_95` 为固定议题内区组 bootstrap 区间，不重采样议题、不向议题总体泛化。
- 正式实验启动前，须先完成双人独立审核与第三人裁决、真实受试流程接入、以及预实验范围/预算另行确认。
