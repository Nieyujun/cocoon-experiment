## 3. 反 AI 味硬门禁（`verify_five_minute_showcase`）

核验顺序：凭据扫描 → 内嵌数据与重算逐项相等 → 零外链与零 `fetch`/XHR → 仅 2 个 script、1 个 style → **`_ui_sandbox_audit`** → **`_payload_truth_audit`** → 整页逐字节重建比对。

`_ui_sandbox_audit` 的检查项如下（去掉 `<script id="showcase-data">` 后检查）：
1. Emoji 正则 `[\U0001F300-\U0001FAFF\u2600-\u27BF\uFE0F]` 命中数为 0（`ui_emoji_forbidden`）。
2. 禁止 `background-clip:text`（`ui_gradient_text_forbidden`）和 `linear-gradient`（`ui_gradient_button_forbidden`）。
3. `#teleprompter` 带 `hidden` 类；抽屉 class 只能是 `drawer` 且 `aria-hidden="true"`；遮罩带 `hidden`。
4. `#scene-0`…`#scene-3` 各含一个 `svg.sandbox`（id 固定），去掉 SVG、h2、按钮、链接后的汉字数不超过 45。
5. 必须有诚实角标。

`_payload_truth_audit` 把嵌入数据与原始来源逐项比对：S01/S02 的发言和 mirror；四轮 I4/I5 字数等于清单可见全文长度；七项配对检查全部为真；父快照 64 位哈希等于清单 `parent_t1_core_sha256`；回应全文和气泡是逐字子串（≤24）；主终点 Brier I4=I5=0.0025；迁移 4.0 对 3.0；O 58.3 对 33.3；双轨序列；Q5 含 XL_E03/XL_E06；全页只有一处错位旗标；角标四个关键词齐全。
