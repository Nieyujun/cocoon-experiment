# 信息茧房与破茧助手：中期进展

我们想了解：持续接触相近观点和错误信息，会不会让判断出错、过度自信，或忽略重要证据？补充可靠信息和引导反思，能否改善这些问题？

这是第十八小组的课程项目。目前已完成助手原型、实验程序和小规模模型试验。开题中的连续群体互动、四种信息环境比较和分项干预实验还没有全部完成。

## 先看这两个入口

下载仓库后，用浏览器打开根目录的 **[index.html](index.html)**：这是面向老师的中期展示。保留原版的四幕动画：实验怎么做、阅读后的变化、干预怎么做、目前的结果。详细原文按需展开，“中期进展”里说明已完成工作和下一步。

**[assistant.html](assistant.html)** 是独立的破茧助手。保留原来的体验顺序：选择模式 → 输入话题 → 逐步分析 → 查看报告 → 用“认知镜”反思自己的看法。这次只调整视觉样式和少量界面文字。

无需密钥的“示例体验”使用内置内容，不属于实验数据。连接模型仍沿用原版行为：没有独立联网核查能力，部分调用失败会退回模拟内容。直接双击打开网页时，请选示例体验；连接模型需通过下方本地服务打开，且模型服务允许浏览器连接。

GitHub 文件预览不会执行网页。请下载到电脑后打开，或在项目目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，再访问 `http://127.0.0.1:8000`。

## 已经完成的工作

- 助手能按步骤整理信息、标注来源、寻找遗漏、形成报告，并结合用户原话提出反思问题。
- 实验程序能分配四种信息环境的材料，保存阅读经历，复制干预前状态，并进行四次测量与评分。
- 已围绕气候、能源、天气三个现实议题，以及一个虚构交通情境，开展真实模型的小规模试验。每个情境只有两名模型读者，不是真人受试者。
- 已保存材料、模型回答、失败尝试和评分结果，方便回查。另有使用程序生成回答的流程演练，它只用于检查程序，不作为研究结果。

## 目前观察到了什么

**现实议题在开始时就被答对了。** 三个议题中，模型在阅读材料前的核心事实正确率已经是 100%。这限制了我们通过正确率观察信息环境和干预的作用。

**虚构情境中，提供证据改善了回答，但加入反思暂未显示额外优势。** 直接提供核查证据、提供同样证据并加入助手反思的两组，核心事实正确率都从 50% 升到 100%，后续四轮阅读后保持。这里的初始 50% 来自真假概率均填 0.5 的计分规则，不表示模型知道一半答案。

模型在发言中转述过错误数字，但答题时仍表示不确定，没有出现预期中的明显高信心错误。其他评分有高有低，加上样本很小，目前不能据此判断助手整体更有效。

结果出处：[现实议题汇总](experiment/review/live_micro_pilot_20261111/three_topic_live_micro_pilot_matrix.json)、[虚构情境记录](experiment/review/live_micro_pilot_20261111/closed_world_synth01_live_pilot.json)。

## 距离开题目标还差什么

| 开题要完成的事 | 当前进展 | 最终阶段计划 |
|---|---|---|
| 模拟用户连续看信息、讨论并记住经历 | 当前真实试验主要先累积阅读材料，再让模型发言、答题 | 补上逐轮发言、读取他人回应与记忆更新 |
| 比较均衡/同质、准确/含错误信息四种环境 | 分配程序已实现；真实小试验尚未覆盖完整四组对比 | 在相同起点下完成四组运行，并增加独立重复 |
| 分别比较补充异见、纠错和反思 | 当前主要比较基础对照、证据、证据加反思 | 把三种方法分开检验，匹配阅读量和互动机会 |
| 用一致标准判断效果 | 四次测量和主要评分已实现 | 人工复核材料、引用与评分，报告有效、无效和不确定的结果 |

下一阶段以补齐这些实验为主，不预设一定会得到“助手更有效”的结果。更详细的说明见 **[中期报告](docs/中期报告.md)**。

## 项目文件怎么找

| 位置 | 内容 |
|---|---|
| `index.html`、`assistant.html`、`web/` | 当前中期展示与助手界面，无需安装前端依赖 |
| `cocoon/` | 实验与助手程序：材料分配、模型调用、测量、评分和记录 |
| `configs/` | 实验设置及给模型的任务说明 |
| `experiment/` | 历史材料、模型回答、结果清单及原始展示产物 |
| `vendor/` | 原始助手网页和提示词，保留用于核对实验版本 |
| `tests/` | 程序功能检查；通过测试不等于验证了研究假设 |
| `docs/` | 中期报告和维护说明 |

`experiment/` 里的旧看板、讲稿和“结案”报告是之前的工作记录，不作为当前中期汇报入口，也不代表开题已全部完成。原始文件保留用于核对数据，新展示不提供讲稿、提词器和答辩问答抽屉。

## 本地运行与维护

查看新页面只需要浏览器。运行实验程序需要 Python 3.10 或更新版本；部分历史配置保留原作者电脑路径，实际运行前需调整。通用正式实验入口仍关闭，小规模模型运行需要另外配置服务、凭据和预算。

本次界面更新不重新运行付费实验，也不改动历史材料与评分。原始五阶段实验助手在 `cocoon/assistant.py`；网页交互保留在 `assistant.html`，外观调整在 `web/assistant-polish.css`。两者用途不同：前者执行受控实验，后者供人体验助手流程。

历史测试报告记录了 1053 项离线检查通过，这是此前的测试记录，不代表每次改动都已重跑，也不包含真人审核。界面维护与检查方式见 [维护说明](docs/维护说明.md)。
